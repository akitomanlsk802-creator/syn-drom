4) รีแฟกเตอร์จุด “เสี่ยงพัง” ให้เข้ากับสคีมาใหม่

A) เวลาใน Hive → int นาที

ค้นหาในโค้ดเก่า: TimeOfDay, format(context), hour/minute

แทนที่ด้วย: toMinutes(TimeOfDay) และ toTimeOfDay(int)

เก็บลง Hive เป็น int เท่านั้น

B) BreakPeriod

ถ้าเคยใช้ @HiveType() → ลบทิ้ง และเปลี่ยนเป็น Map<String,dynamic>

โครงที่รองรับ:
{ "name": String, "startMinutes": int, "endMinutes": int, "enabledDays": List<int> }

Validation “ไม่ซ้อนช่วง” ใช้ใน SettingsController.save() หรือสร้าง helper ใน service

C) Notification / Background

เรียกใช้ NotificationService.scheduleAt() ที่เราเขียน (FLN 19 + exactAllowWhileIdle)

ห้ามใช้ android_alarm_manager_plus ซ้ำกับ WorkManager

BackgroundScheduler.ensureRegistered() ต้องถูกเรียกใน main()

D) Import/เส้นทาง

เปลี่ยน import แบบเก่า → relative path (เช่น ../services/...) ให้ตรงโครงใหม่

ลบ import / adapter เก่าที่ไม่ใช้ → flutter clean
